# AERO — Air Motion

A cinematic, scroll-driven product website concept for a fictional sneaker brand, designed and built by [TrueStackit](https://truestackit.com).

**Live:** https://mustafacoder365.github.io/aero-air-motion/
**Auto-play demo:** https://mustafacoder365.github.io/aero-air-motion/?demo

- 4 scroll scenes: intro, transformation, details, reveal
- GSAP + ScrollTrigger, scrubbed timeline, portrait and landscape layouts
- Plain HTML/CSS/JS, no build step

AERO is a fictional brand created for this concept. It is not a real product.
